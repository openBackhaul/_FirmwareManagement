# Integrated Approach

The following roles interact with the FirmWareManager via diverse tools:  

- Engineering  
  documents firmware approvals
- Operation  
  creates device groups and associated firmware versions  
  analysis unexpected situations via ticketing system
- Planning  
  sorts devices into device groups
